# Архитектура

```
ros2 bag play ──▶ облако точек (PointCloud2)
                        │
                        ▼
          lidar_obstacle_detector (ROS 2 нода)
                        │
                        ▼
                 detector.Pipeline
   ┌──────────────┬──────────────┬──────────────┬──────────────┐
   │ pointcloud   │ geometry     │ path         │ detect       │ tracking
   │ разбор полей │ калибровка,  │ ось и уровень│ габарит,     │ подтверждение
   │ PointCloud2  │ система пути │ пути вдаль   │ кластеры     │ по кадрам
   └──────────────┴──────────────┴──────────────┴──────────────┘
                        │
                        ▼
  /obstacle/status    JSON с результатом кадра
  /obstacle/detected  есть ли препятствие
  /obstacle/distance  расстояние до ближайшего, или -1
  /obstacle/markers   габарит и рамки объектов для RViz
  /obstacle/points    точки внутри габарита для RViz
```

## Компоненты

| Модуль | Назначение |
|---|---|
| `detector/pointcloud.py` | разбор `PointCloud2` по описанию полей, отбрасывание пустых точек |
| `detector/geometry.py` | плоскость пути, поиск рельсов, перевод точек в систему пути |
| `detector/path.py` | построение оси пути и уровня рельсов вдаль по рельсам и стенам |
| `detector/detect.py` | профиль габарита, кластеризация, фильтры |
| `detector/tracking.py` | сопоставление объектов между кадрами и подтверждение |
| `detector/pipeline.py` | сборка шагов, результат кадра |
| `detector/config.py` | параметры и их загрузка из YAML |
| `ros2_ws/src/lidar_obstacle_detector` | ROS 2 нода, launch, конфиг RViz |
| `tools/run_bag.py` | прогон записи без ROS, результат в JSON Lines |
| `tools/render_video.py` | видео с результатом по записи |
| `tools/evaluate.py`, `tools/eval_synthetic.py` | метрики по результатам |

Ядро `detector` не зависит от ROS. Одна и та же логика работает в ноде, в офлайн-прогоне и в тестах.

## Система координат

Лидар смотрит вперёд по оси минус Y, как в выданных записях. Направление задаётся параметром
`forward_axis`. Все расстояния в результате считаются вдоль пути от лидара.

## Производительность

Кадр обрабатывается за время, сопоставимое с периодом лидара, на одном ядре CPU. GPU не нужен.
Если нода не успевает, она берёт самый свежий кадр и пропускает старые, поэтому задержка не накапливается.
